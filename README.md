E-Commerce Sales & Customer Analysis

Project Overview

This project analyzes an e-commerce sales dataset to understand sales performance, profitability, product categories, customer locations, and business trends.

The project covers data preparation, exploratory data analysis, data visualization, Power BI dashboard creation, and business insights and recommendations.

Dataset Description

The dataset contains 15 records and 13 columns covering orders, customers, products, categories, sales, discounts, profits, locations, quantities, and payment methods.

The dataset was used to analyze:

- Sales performance
- Profitability
- Product category performance
- City-wise sales
- Monthly sales trends
- Payment methods

Tools & Technologies Used

- Python
- Pandas
- Data Visualization
- Power BI
- Git
- GitHub

Data Preparation & Cleaning

The dataset was inspected and cleaned using Python and Pandas.

Cleaning results:

- Original Rows: 15
- Duplicate Rows Removed: 0
- Rows With Missing Values Removed: 0
- Final Rows: 15

The cleaned dataset was saved as "cleaned_ecommerce_sales.csv".

Business Insights

1. Electronics generated the highest sales with ₹157,700.
2. Furniture generated ₹53,500 in sales.
3. Stationery generated the lowest sales with ₹6,500.
4. Delhi had the highest city-wise sales with ₹125,700.
5. January recorded the highest monthly sales with ₹109,500.
6. Sales and Profit showed a very strong positive correlation of 0.951.
7. The highest single-order sales value was ₹55,000.

Recommendations

- Focus marketing and inventory efforts on Electronics.
- Increase promotional activities for Stationery.
- Analyze customer demand in Delhi and apply successful strategies to lower-performing cities.
- Promote high-value and profitable products.

Conclusion

The project demonstrates how data analytics tools can be used to transform raw e-commerce data into meaningful business insights.

Python and Pandas were used for data preparation and analysis, visualization techniques were used to identify trends, and Power BI was used to create an interactive dashboard. Git and GitHub were used for version control and project documentation.
